# 磁盘扩展包 使用说明

> 可选模块 · 多盘分析 · 只删除安全项 · 需要主程序 v2.2.0 或更高

## 一、这是什么

主程序只分析 C 盘。磁盘扩展包是一个**单独的可选工具**，用来扫描其他磁盘：

- 内置固定盘（D:、E: 等数据分区）
- USB 移动硬盘
- U 盘、SD 卡

它不会随主程序自动安装，也不会自动下载。你从 Releases 手动下载、解压、放到程序目录后，
主程序侧栏底部会出现「磁盘扩展包」，点一下即可打开。

## 二、安装

1. 下载 `c-drive-cleaner-<版本>-disks.zip`。
2. 解压出 `磁盘扩展包.exe`。
3. 放到下面任意一个位置：
   - 主程序所在目录（和 `C盘清理助手.exe` 并排）
   - `%LOCALAPPDATA%\C盘清理助手\dlc\磁盘扩展包.exe`
4. 回到主程序，点侧栏底部「磁盘扩展包」。

也可以直接双击 `磁盘扩展包.exe` 独立运行。

## 三、两种扫描

| 模式 | 做什么 | 大概耗时 |
|---|---|---|
| 快速扫描 | 遍历目录、统计体积、识别回收站/Steam 缓存/下载目录 | 内置 SSD 1–3 分钟；USB 移动硬盘 5–15 分钟 |
| 深度扫描 | 在快速基础上增加大文件排行、重复文件、超过 2 年未修改的大文件 | 会读取文件内容做哈希，明显更慢 |

扫描过程可以随时「停止」。外接设备扫描期间**不要拔线**。

## 四、结果怎么看

- **可清理**（有勾选框）：只包含安全白名单项——各盘回收站、Steam 着色器缓存、
  Steam 未完成下载、Steam 安装临时目录。
- **仅报告**（灰色、无勾选框）：游戏库、下载目录里的安装包/镜像、大文件、重复文件、
  长期未用文件。这些**不会**被删除，只提供统计和路径，方便你自己判断。

底部汇总会显示：总占用、可清理、仅报告、已选。

## 五、清理规则（重要）

1. 非系统盘上默认只删「安全白名单」，游戏、媒体、文档一律不碰。
2. **备份盘禁止删除**：检测到 `WindowsImageBackup`、`FileHistory` 或卷标含
   Backup / Passport / 备份 时，只能查看统计。
3. **网络盘不列出**，光盘和只读介质不参与。
4. 清理前必须输入 `DELETE <盘符>`，例如 `DELETE D`，输错不会执行。
5. 以下路径永远拒绝：卷根、`System Volume Information`、`$Recycle.Bin`、
   `Windows`、`Program Files`、`ProgramData`、`EFI`、`Recovery`、
   `pagefile.sys`、`hiberfil.sys`、`swapfile.sys`，以及任何经过 junction/符号链接的路径。
6. 删除是永久的，不进回收站。请先用「快速扫描」看清楚再决定。

## 六、日志

每次清理都会写日志：

```
文档\C盘清理助手\Disk-Clean-Log-<时间>.log
```

包含磁盘序列号、每一项的路径、删除结果、失败原因、实际释放空间和总用时。

## 七、常见问题

**Q：为什么主程序里点「磁盘扩展包」提示找不到？**
A：模块没有放在程序目录或 `%LOCALAPPDATA%\C盘清理助手\dlc\`，按第二节放好即可。

**Q：为什么 F 盘（备份盘）不能清理？**
A：检测到备份特征后强制只读。这是故意的，避免误删备份。

**Q：清理时提示拒绝访问？**
A：其他用户的回收站需要管理员权限。从主程序（管理员）启动模块即可。

**Q：扫描很慢？**
A：USB 机械硬盘随机读取慢，属正常。先用快速扫描，确认目标后再深度扫描。

**Q：会联网吗？**
A：不会。磁盘扩展包没有任何网络请求。
