# 使用说明

适用于 v2.x。提供安装版和便携版两种用法。

> **永久删除**：清理不进回收站，程序也无法恢复。第一次请先用「仅演练」看一遍。

---

## 零、安装或直接运行

**安装版**（推荐）：下载 `c-drive-cleaner-<version>-setup.exe`，双击安装。

- 安装到 `C:\Users\<你>\AppData\Local\Programs\C盘清理助手`，**安装过程不需要管理员权限**。
- 自动创建开始菜单项，桌面快捷方式可选。
- 卸载入口在「设置 → 应用 → 已安装的应用」里。
- 安装后「运行程序」仍会在清理时请求管理员权限，这是正常的。

**便携版**：下载 `c-drive-cleaner-<version>-portable.zip`，解压到任意目录，直接运行
`C盘清理助手.exe`，不写注册表、不建快捷方式。

两个文件都可对照 `SHA256SUMS.txt` 校验。

## 一、运行环境

- Windows 10 1809+ / Windows 11（64 位）
- .NET Framework 4.8（系统自带，无需安装）
- 管理员权限（清理系统目录必需）

## 二、首次运行

1. 双击安装后的快捷方式，或便携版 `C盘清理助手.exe`。
2. 弹出 UAC → 点「是」。点「否」程序直接退出，不会做任何事。
3. 如果出现 SmartScreen「已保护你的电脑」：点「更多信息」→「仍要运行」。
   原因是程序没有代码签名证书，不是文件损坏。
4. 部分杀软可能因为「程序会删除文件」而报警，加入信任即可。


## 三、界面

左侧 6 个页面：

| 页面 | 内容 |
|------|------|
| 概览 | 磁盘占用、可清理 / 推荐 / 仅统计、分类汇总 |
| 可清理 | 勾选清单，可按分类筛选，默认只勾推荐项 |
| 仅统计 | 个人数据与大型软件，只统计、不可删除 |
| 排行 | 目录占用 Top 30、最大文件 Top 60 |
| 建议 | 针对本机的清理与迁移建议 |
| 日志 | 最近一次清理的完整记录 |

右上角：**导入计划 / 导出报告 / 重新扫描 / 开始清理**。

## 四、扫描

- 点「重新扫描」或按 F5。
- 程序遍历整个 C 盘，只读，不改任何文件。
- 底部状态栏实时显示文件数、目录数、已读体积；可随时「取消」。
- 完成后跳到「总览」，并自动勾选推荐项。

## 五、清理

1. 到「可清理」页调整勾选（顶部下拉框可按分类筛选，勾选状态跨筛选保留）。
2. 点「开始清理」或按 Ctrl+Enter。
3. 确认框核对清单与总大小：
   - 输入 `DELETE` 才会解锁「确认删除」；
   - 勾「仅演练」则只统计不删除。
4. 清理在后台进行，底部显示进度；完成后弹结果并跳到「日志」页。
5. 结果包含 C 盘可用空间变化、实际释放、未能删除的条目数。

## 六、导入 / 导出

导出报告会在 `文档\C盘清理助手\` 生成：

- `C-Clean-Report-<时间>.html` —— 浏览器打开的可视化报告
- `C-Clean-Plan-<时间>.json` —— 清理计划

导入计划可直接读取 JSON，不必重新扫描；计划里只有清单，没有目录排行。

## 七、快捷键

| 快捷键 | 功能 |
|--------|------|
| F5 | 重新扫描 |
| Ctrl + 1…6 | 切换页面 |
| Ctrl + E | 导出报告 |
| Ctrl + Enter | 开始清理 |
| Esc | 关闭确认框 |

## 八、更新提醒

- 启动后最多每 24 小时查一次 GitHub 的 `releases/latest`。
- 有新版时窗口顶部出现横幅：「发现新版本 x.y.z（当前 a.b.c）· 查看 · 忽略此版本」。
- 「查看」打开 Release 页面，程序不会自动下载或安装。
- 「忽略此版本」之后不再为这个版本提示。
- 侧栏底部「设置」可以关闭自动检查，也能手动「立即检查更新」。
- 网络失败时静默，不影响任何功能。

## 九、命令行参数

```text
C盘清理助手.exe --scan                       启动后立即扫描
C盘清理助手.exe --plan="plan.json"           导入计划
C盘清理助手.exe --plan="plan.json" --dry-run 只演练，不删除
C盘清理助手.exe --page=3                     启动后停在指定页（0–5）
C盘清理助手.exe --no-elevate                 不请求管理员（只读模式）
C盘清理助手.exe --no-update-check            完全不联网检查更新
```

## 十、安全机制

1. 扫描只读；清理前必须输入 `DELETE`。
2. 每条待删路径都经过白名单校验，任意一条不合法则整次清理中止。
3. 不跟随 junction / 符号链接，只删链接本身。
4. 只处理 C 盘。
5. 个人数据（微信 / QQ / 钉钉、下载、桌面、文档、视频、游戏本体、Docker 数据盘）
   只统计、不提供删除。
6. 每一项、每个失败文件都写入日志。

## 十一、常见问题

**Q：为什么「可清理」里的大小合计比磁盘已用空间还大？**
WinSxS、DriverStore 存在大量硬链接，同一份数据被多个路径各算一次，界面已注明。

**Q：为什么有些项目显示「需管理员」？**
当前进程没有读到该目录。以管理员身份重新扫描即可；清理时也会先复测真实大小。

**Q：清理时提示「N 个文件未能删除」？**
文件正被占用。关掉浏览器 / IDE / 微信等再试，日志里有具体文件名。

**Q：DISM 清理很久没反应？**
正常，5–15 分钟，期间磁盘占用高。清理后无法卸载旧更新。

**Q：NVIDIA 缓存为什么有几十 GB？**
显卡驱动的着色器缓存（`.nvph`）回收不及时是已知问题，纯缓存，删掉会自动重建，
首次进游戏可能略有卡顿。

**Q：能恢复删掉的文件吗？**
不能。程序没有隔离区，删除即永久；请先用演练模式确认清单。

**Q：怎么卸载？**
删除程序文件夹即可。程序不写注册表、不装服务，只在 `文档\C盘清理助手\` 留报告和日志。

## 十二、从源码构建

```powershell
git clone https://github.com/Misaka-11736/c-drive-cleaner.git
cd c-drive-cleaner
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

不需要 Visual Studio 或 .NET SDK，使用系统自带的 `csc.exe`。
